How do I read this table?

Rows are alternatives you can choose. Columns are states of nature you cannot control. Each payoff is the net benefit of that combination. Negative values represent losses. Probabilities must add up to 1 for EMV.

02 Four criteria, different perspectives

AUTO UPDATE

Each criterion compares the complete original set of alternatives. Ties are retained.

Comparison summary

Regret table and formulas

Regret = best payoff in a state − the alternative's payoff. Maximax chooses the highest maximum. Maximin chooses the highest minimum. Minimax Regret chooses the lowest maximum regret. EMV = sum of (payoff × state probability).

Displayed values use two decimals; calculations keep full precision. Values within an absolute tolerance of 10⁻⁹ of the best value or cutoff are treated as tied.
